# Pirate_Maze_Agent

<H1>Briefly explain the work that you did on this project:</H1>
<H2>What code were you given?</H2>
<P>In this project we were given the TreasureMaze Class, GameExperience Class, and sections that allowed us to visualize the maze, define actions, and other various helper functions. The TreasureMaze class represents the maze environment as an 8x8 matrix where the pirate is made to navigate. The GameExperience class manages the experience replay for the Q-learing algorithm by storing the episodes of state transitions. We were also supplied with the neural network model definition and training framework.</P>
<H2>What code did you create yourself?</H2>
<P>The code that I created by myself was the implementation of the Q-training Algorithm within the 'qtrain' function. This involved initializing the environment and experience replay, training the model over multiple epochs through iteration, using the epsilon-greedy policy to balance the exploration vs. exploitation of the agent, storing and replaying experiences to train the neural network model, and last but not least, monitoring the training progress and adjusting the epsilon based on stage and win rate.</P>
